# Bloemist Roos (demo): contentkaart

Demo-site van Sitepraat (DoLessWithAI). Statische site: `npm run build` maakt `dist/` uit de bronnen.

| Inhoud | Bron |
|---|---|
| Naam, slogan, adres, telefoon, openingstijden | `content/site.json` |
| Prijzen | `content/prijzen.json` |
| Algemene voorwaarden | `content/voorwaarden.json` |
| Opmaak van elke pagina (menu, footer) | `src/template.html` |
| Kleuren en stijl | `src/style.css` |

Regels: prijzen als `€ 7,50`. `dist/` nooit aanpassen.
